# NC plus one

This is a backend project for managing events and rsvps
The app will store information about users, events, venues and RSVPs, allowing users to create and attend events at different venues

## Run instructions

run this command to create the database
    -psql -f db/setup.sql

## Environment setup

Create a .env file in the root of the project, it should contain your pistgresql credentials similar to the .env.example file
